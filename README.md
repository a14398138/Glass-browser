# Glass Browser 0.5.0 — POCO F7 / HyperOS 3 試作

## 0.5.0の変更

添付画像の外枠（約幅540×高さ800）に近い、幅2：高さ3に変更しました。初期サイズは320×480dpを基準に画面に収めます。四隅のリサイズでも2:3を維持します。更新後の初回は旧比率のサイズをリセットします。

## 基本機能

- 下バーを下へスワイプすると、独自小窓の拡大ではなく、通常の不透明なFullscreenActivityを前面に開きます。専用タスクとして最近使ったアプリに残ります。画面の開始通知を受けてから小窓のサービスを終了します。
- 全画面の「小窓に戻す」で独自フローティングへ戻れます。全画面はホーム・最近使ったアプリ・戻るなど通常の操作ができます。
- 小窓は幅:高さ = 2:3のスマホ型。初期幅320dpを基準に画面へ収め、四隅で比率を保って拡大縮小します。旧版の横長サイズは初回に更新します。
- 「入力」ボタンを廃止。URL欄・Webページの入力欄をタップして入力します。小窓の外をタップするとフォーカスを解放します。上辺・角のドラッグは入力フォーカスを取りません。
- 光るエッジ装飾を削除。小窓全体の不透明度を96%とし、本文領域に約8%の薄い色、メニューに約40〜60%の濃い色を重ねます。写真には別途従来の濃さ設定が適用されます。背景のリアルタイム屈折・ぼかし処理はありません。

## インストールと起動

1. `GlassBrowser-0.5.0.apk`を開いて上書きインストールします。前回と同じアプリID・署名です。
2. 初回はホームから起動し、必要なら「他のアプリの上に表示」を許可して戻ってください。通知を許可すると通知からも終了できます。
3. サイドバーにGlass Browserを手動で追加し、動画再生中に開いてください。追加候補に出ない場合はホームから起動し、動画アプリへ戻って試せます。

## 操作

| 操作 | 方法 |
|---|---|
| 移動 | 上辺または上部中央の文字をドラッグ |
| 拡大縮小 | 四隅をドラッグ。2:3の比率を維持 |
| 通常の全画面タスクへ | 下バーを下にスワイプ、またはメニューの「全画面」 |
| 小窓を終了 | 下バーを上にスワイプ、右上 ×、または通知の「閉じる」 |
| 全画面から小窓へ | 全画面の操作パネルにある「小窓に戻す」 |
| 操作パネルの開閉 | ☰ |
| 入力 | URL欄・ページの入力欄をタップ |
| 画像 | 「画像」を押して薄く／枠／非表示を切り替え、スライダーで濃さを調整 |
| ページ表示の修復 | 透過OFFで通常表示へ戻す |

下バーは48dp以上かつ縦方向が優勢なスワイプで反応します。透明な部分も小窓内はブラウザのタッチ領域で、背後へタップは通りません。

## 引き継ぎと確認点

- 小窓と全画面の切り替えではWebViewのURL・閲覧履歴を受け渡し、Cookieは共有します。ページは再読込されるため、スクロール位置や未送信の入力内容は保持を保証しません。
- HyperOSが通常タスクの起動を制限した場合、小窓は開始確認を待ち、確認できなければ残ります。実機での切り替え動作は未確認です。
- 小窓の自動入力・キーボードの位置と表示、入力後の動画継続、全画面の最近使ったアプリ表示、半透明の実際の見た目を実機で確認してください。
- 背後のアプリ自身がフォーカス変更や他のアプリの表示で動画を停止する場合があります。
- 全画面は通常のアプリ画面として濃い背景を持ちます。全画面まで背後が透けるオーバーレイにはしません。

## 技術・互換性

Android 10以上、compile/target SDK 35。独自オーバーレイの継続表示にspecialUseのフォアグラウンドサービスを使用。root、Shizuku、アクセシビリティサービスや画面取り込みは不要です。

必要な宣言権限はINTERNET、SYSTEM_ALERT_WINDOW、FOREGROUND_SERVICE、FOREGROUND_SERVICE_SPECIAL_USE、POST_NOTIFICATIONS。ユーザー操作から起動し、終了操作で停止します。

Xを含む全サイトの動作は未保証です。第三者Cookie、外部アプリ認証、ファイル添付、ポップアップには未対応。別オリジンiframe、Shadow DOMや特殊な描画は透過調整が不完全な場合があります。独自の解析通信やJavaScriptネイティブブリッジはありません。

## ソースからビルド

Android Studioでsourceフォルダを開いてください。JDK 17、Gradle 8.11.1、Android Gradle Plugin 8.9.2、SDK 35を指定しています。Gradle導入済みなら `gradle :app:assembleDebug`。
GitHub Actionsのビルド設定も同梱。リポジトリ操作やActions実行はしていません。

配布APKはECJ・aapt2・D8・zipalign・apksignerでビルド。署名鍵は同梱していません。別の署名でビルドしたAPKは、上書きできない場合があります。
